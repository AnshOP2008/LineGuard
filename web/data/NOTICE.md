# Dashboard data attribution

The `runs/` exports use transformed SKAB readings and labels (Katser and Kozitsin, GPL-3.0; see GPL-3.0.txt). The [original CSVs](https://github.com/waico/SKAB/tree/master/data) and `lineguard/export.py` document the source and transformation. Synthetic sensor scenarios are marked as injected.

Hydraulic evaluation outputs use [UCI dataset 447](https://doi.org/10.24432/C5CW21) (Helwig, Pignanelli and Schuetze, 2015, CC BY 4.0). The cycle data has been transformed into model predictions and evaluation summaries. The project code is MIT.
